### 🎯 Next Steps

#### 1️⃣ Setup Supabase (5 minutes)
```
1. Go to https://supabase.com
2. Create a new project
3. Go to Settings → API
4. Copy Project URL and Anon Key
5. Create .env file from .env.example
6. Paste credentials
```

#### 2️⃣ Create Database Table (2 minutes)
```
1. In Supabase, go to SQL Editor
2. Click "New Query"
3. Copy the SQL from INSTALLATION.md → "Create Database Table" section
4. Execute the query
5. Enable Email/Password in Authentication
```

#### 3️⃣ Install Dependencies (1 minute)
```bash
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

#### 4️⃣ Run Application (30 seconds)
```bash
streamlit run app.py
```

App opens at: http://localhost:8501

### 📊 Main Table Schema

Your database table `MainTable` has these columns:

```
id              → Auto-increment primary key
created_at      → Auto-generated timestamp
first_name      → Required
last_name       → Optional
email           → Required, unique
mobile          → Required
number          → Optional
category        → Junior, Senior, Professional, Amateur
match_status    → Registered, Pending, Confirmed, Cancelled
tournament      → Cricket, Badminton, Table Tennis, Football
sabha_reference_name → Optional reference
spl_no          → Optional SPL number
image           → Optional image URL
```

### 📝 CSV Format for Bulk Upload

```csv
first_name,last_name,email,mobile,number,category,match_status,tournament,sabha_reference_name,spl_no,image
```

### 🐛 Troubleshooting

If something doesn't work:

1. **Check .env file exists** with correct credentials
2. **Check Supabase table is created** in SQL Editor
3. **Enable Email/Password** in Supabase Authentication
4. **Clear cache**: Click "Refresh" button in app
5. **Check Python installed**: `python --version`

See **INSTALLATION.md** for detailed troubleshooting.
